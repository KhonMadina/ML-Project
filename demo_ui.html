    Batch prediction & CSV export

      5. Programmatic access
      
      
      API reference
      
      
      The browser UI is a thin client over a FastAPI backend. Use the same endpoints in experiments or external systems.
      
      
        
        
      • GET /health → status and model info.
        • 
        
      • GET /meta → model information, label set, and supported model types.
        • 
        
      • POST /predict with JSON {"text": "...", "model_type": "baseline|transformer", "tau": 0.5, "normalize": true} → prediction, probabilities, conformal set, uncertainty, importance.
        • 
        
      • POST /predict/batch with JSON [{"text": "...", "model_type": "...", "tau": 0.5, "normalize": true}] → list of predictions.
        • 
        
      • Interactive docs: /docs
